# DIANA MOBILE MOTION STUDIO

**iPhone арқылы кәсіби Reels монтажы.** Сіз видеоңызды немесе дауыс жазбаңызды жібересіз, стиліңізді айтасыз, раскадровканы (сторибордты) көріп мақұлдайсыз — Claude дайын MP4 видео мен мұқабаны жасап береді.

Компьютер керек емес. Ештеңе орнатудың қажеті жоқ. Бәрі Claude Code бұлтында жұмыс істейді.

## Не істей алады
- 🎙 **Тек өз дауысыңыз** — видеодағы сөзіңіз немесе MP3/M4A/WAV жазбаңыз. Жасанды дауыс жоқ.
- ✍️ **Қазақша, орысша, ағылшынша субтитрлер** — сөйлеген сөзге сәйкес, белсенді сөз ерекшеленеді. Сценарий мәтінін берсеңіз — субтитр сол мәтінмен дәл шығады.
- 🙂 **Бетті қорғау** — мәтін бетті жаппайды (MediaPipe бетті және шашты анықтайды).
- 📱 **Instagram қауіпсіз аймақтары** — мәтін батырмалар мен сипаттаманың астында қалмайды.
- 🎬 **Камера қозғалысы** — бетке бағытталған зум, склейкалар, жұмсақ наезд.
- 🔠 **Бастың артындағы жазу** — үлкен сөз адамның артында тұрады.
- 🔵 **Шеңбер және бөлінген экран** — адамды шеңберге салу, экранды екіге бөлу (үстінде фото/видео, астында сіз).
- ✨ **Мағынаға сәйкес иконкалар** — «телефон», «ақша», «уақыт», «жазылыңыз» деген сөздерде анимацияланған иконка шығады.
- 🔊 **Дыбыс эффектілері** — акцентте, иконкада, план ауысқанда (дауыстан тыныш).
- ⬛ **Форматтар** — 9:16, 1:1, 4:5, 16:9.
- 🎨 **5 стиль**: brand, minimal, kinetic, glass, lime + өз түстеріңіз.
- 🖼 **Мұқаба** — видеодан ең жақсы нақты кадр, профиль торына сай.
- ✅ **Сапа тексеруі** — дыбыс деңгейі, формат, мәтін орны автоматты тексеріледі.

## Қалай бастау керек (бір рет, ~5 минут)
1. Осы беттегі **Use this template → Create a new repository** басыңыз. **Private** таңдаңыз.
2. Телефондағы **Claude** қосымшасында **Code** бөлімін ашып, GitHub-ты қосыңыз және жаңа репозиторийіңізді таңдаңыз.
3. Жаңа сессия ашып, видеоңызды тіркеп жазыңыз: **«Осы видеоны монтаждап бер»**.

Толығырақ: [STUDENT-GUIDE.md](STUDENT-GUIDE.md) · Не жазуға болады: [COMMANDS.md](COMMANDS.md) · Мәселе болса: [TROUBLESHOOTING.md](TROUBLESHOOTING.md)

## Жұмыс тәртібі
**Талдау → Раскадровка → Сіздің мақұлдауыңыз → Рендер → Мұқаба → Сапа тексеруі → Файлдар телефонға.**
Сіз «мақұлдаймын» демейінше, финал видео жасалмайды.
