# DIANA MOBILE MOTION STUDIO — Architecture v2

Статус: **v2 по окончательным требованиям владельца (2026-11-22).** PHASE 1–3 выполнены.
Предыдущая версия (с TTS) сохранена в ветке `backup/phase3-with-tts`.

## 0. Окончательные требования (кратко)
1. **Только собственный голос пользователя.** Никакого TTS, синтеза, клонирования или замены голоса.
2. Аудио обрабатывается автоматически: длительность → распознавание речи → таймкоды → субтитры → синхронизация анимаций → монтажный план. Если распознавание недоступно — импорт текста с таймкодами.
3. Пользователь делает только: загрузить материалы → написать пожелания → посмотреть сториборд → одобрить/исправить → получить MP4 и обложку.
4. Универсальный GitHub Template: код, Skills, шрифты, анимации и инструкции — в репозитории; никаких личных настроек.
5. Без ручной установки моделей учениками.

## 2. Распознавание речи — выбор и обоснование

| Вариант | Без установки учеником | Бесплатно | Казахский | Проверено |
|---|---|---|---|---|
| **sherpa-onnx + Whisper large-v3-turbo + Silero VAD, локально** | ✅ модели качаются автоматически с официальных релизов GitHub `k2-fsa/sherpa-onnx` (в стандартной сети разрешены), SHA-256 закреплены в коде | ✅ | ✅ (с ошибками, см. ниже) | ✅ ru/en/kk в этой сессии |
| faster-whisper / whisper.cpp / Piper-модели | ❌ модели на huggingface.co — закрыт по умолчанию | ✅ | ✅ | — |
| GitHub Actions + faster-whisper | ⚠️ нужно отправлять аудио в репозиторий, ждать CI | ✅ (лимиты минут) | ✅ | — |
| Платные API (OpenAI, ElevenLabs Scribe, Deepgram) | ❌ нужен ключ каждого ученика + разрешение хоста | ❌ платно (~$0.006+/мин) | частично | — |
| npm-пакеты с «вшитыми» моделями от неизвестных авторов | ✅ | ✅ | ? | ❌ отклонено: непроверяемое происхождение |

**Выбрано: sherpa-onnx (Apache-2.0) + Whisper large-v3-turbo int8 (MIT) + Silero VAD (MIT), CPU.**
Это лучший найденный вариант, который работает в стандартном окружении без настройки и без оплаты.

Измерено в этой сессии (4 ядра):
- первая загрузка модели ≈ 564 МБ, ~1–1,5 мин; далее в этой сессии — из кэша;
- 14,7 с русской речи → 7,8 с распознавания;
- русский/английский: почти без ошибок;
- **казахский: заметно больше ошибок** (тест на синтетическом голосе; на живом голосе ожидается лучше, но гарантий нет).

**Как система компенсирует слабости (реализовано и протестировано):**
1. **Текст сценария → точные субтитры.** Если пользователь прислал текст, в субтитры идут его слова, а время берётся из записи (выравнивание по словам и паузам). На казахском тесте это дало правильную разбивку при 29% распознанных слов.
2. **Защита от «зацикливания» Whisper** («ағағаға…», «да да да…»): такие фразы не попадают в субтитры, их время сохраняется, пользователь видит пометку.
3. **Фильтр типичных галлюцинаций** («Продолжение следует», «Thank you for watching»).
4. **Обязательная проверка текста в сториборде** (`needsReview`) — пользователь правит текст фразами «исправь слово…».
5. **Честные метки тайминга:** границы фраз — измерены по аудио (VAD); отдельные слова — оценка внутри фразы.
6. **Импорт** SRT / VTT / «0:00 текст», если распознавание недоступно.

## 3. Режимы

| | expert-video | voice-over-visuals |
|---|---|---|
| Вход | видео (одно или несколько) с речью пользователя | аудиозапись пользователя (MP3/M4A/WAV…) + фото/видео без речи, либо только графика |
| Голос | речь из видео | аудиозапись |
| Видеоряд | исходное видео (smart crop — PHASE 5) | фото (Ken Burns), b-roll, анимационная графика |

Автоопределение (`src/core/modes.ts`): если неясно, какой звук — голос (есть и запись, и видео с речью; две записи; видео без речи; только фото) — система **спрашивает**, а не угадывает. Синтетический голос как вариант не предлагается никогда.

## 4. Подготовка материалов (`npm run new`)
- **Видео** → proxy H.264 8-bit yuv420p BT.709, постоянная частота кадров (30 fps по умолчанию), учтён поворот, HDR (HLG/PQ iPhone) → SDR через tone mapping `mobius`.
- **Фото** → JPEG sRGB, учтена EXIF-ориентация, HEIC → JPEG, длинная сторона ≤ 2160.
- **Голос** → 48 кГц мастер, 16 кГц для распознавания, улучшенная копия: highpass 70 Гц, лёгкое шумоподавление, де-эссер, мягкая компрессия, EBU R128 −16 LUFS, true peak ≤ −1,5 dBTP. Без изменения высоты тона и тембра.

## 5. Мобильный процесс ученика

```
Ученик (iPhone, приложение Claude)            Claude (облачная сессия, сам)
──────────────────────────────────            ──────────────────────────────
1. Прикрепляет видео / фото / голос    ──►   npm ci (если нужно), npm run new, npm run transcribe
2. Пишет пожелания по стилю            ──►   storyboard.json + кадры + storyboard.html (PHASE 6)
3. Смотрит сториборд                   ◄──   отправка картинок/HTML в приложение
4. «Одобряю» / «Измени сцену 3»        ──►   правки → новая версия → approval.json (PHASE 7)
5. Получает файлы                      ◄──   рендер → обложка → QC → отправка MP4 и PNG (PHASE 8–10)
```

**Загрузка файлов с iPhone** (проверяется в PHASE 12 на реальном устройстве):
- основной путь — вложение в сообщении Claude; лимиты размера вложений для видео не подтверждены;
- запасной — ссылка Google Drive (в стандартной сети не гарантирован; в окружении владельца разрешён).

**Нулевая настройка для ученика:** SessionStart-хук в репозитории (`.claude/hooks/session-start.sh`) автоматически ставит зависимости в каждой облачной сессии; модели распознавания скачиваются автоматически при первой транскрипции.

## 11. Облачный рендеринг с iPhone — проверка (2026-11-22)

**Вывод: Remotion остаётся внутренним движком. Ученик на телефоне ничего не устанавливает — всё работает в облачной сессии Claude Code.**

|---|---|
| Node.js 22, ffmpeg 6.1, Chromium headless shell в стандартном облачном образе (Ubuntu 24.04) | ✅ предустановлены, ученику ставить нечего |
| Установка проекта с нуля (`npm ci`, 304 пакета, Remotion включён) | ✅ 5 с |

| Рендер Remotion 1080×1920 H.264 (видео + фон + анимированный заголовок + субтитры по словам с казахскими буквами + прогресс-бар) | ✅ кадры проверены визуально |

### Найденная проблема и решение
CSS-размытие полноэкранного видео в браузере без GPU утроило время (10× → 2,7× после исправления).
**Правило архитектуры:** тяжёлые пиксельные операции (размытый фон, цветокоррекция, tone mapping) делает ffmpeg заранее (`blurFillArgs`, 30 с — 2,5 с), а Remotion рисует только наложения: текст, графику, субтитры, переходы. Декодер `@remotion/media` быстрее `OffthreadVideo` (3,4× против 5,4×) — используется он.

### Лицензия Remotion (текст из пакета `remotion@4.0.545/LICENSE.md`, сайт из облака недоступен)
- Бесплатно: «an individual», «a for-profit organization with up to 3 employees», некоммерческие организации — **включая коммерческое использование** для создания видео.
- Компании с > 3 сотрудниками нужна платная Company License.
- Запрещено: «copy or modify Remotion code for the purpose of selling … your own derivate of Remotion». Шаблон не копирует и не изменяет код Remotion — он ставит его из npm как зависимость.
- Применение к курсу: ученик-физлицо или компания ≤ 3 человек — бесплатно; ученик от имени компании > 3 человек — нужна своя лицензия. **Продажа курса с шаблоном — пограничный случай**: рекомендуется письменно подтвердить у Remotion (FAQ: remotion.dev/docs/license/faq). В лицензии указано, что в Remotion 5.0 условия «немного изменятся» — версия зафиксирована на 4.0.545.
