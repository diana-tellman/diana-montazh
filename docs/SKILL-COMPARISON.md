# Үш skill-дің салыстыруы → бір `video-director`

| | 1. `video-director` (репо, бұрынғы) | 2. `video-director` + `editorial-motion` (zip) | 3. `motion-studio` (плагин) |
|---|---|---|---|
| Мықты жағы | бекітусіз рендерге тыйым (хэш), өз дауысы ғана, QC, телефонға жеткізу, 9 бөлек көмекші skill | мағына → кадр (мысал → терезе, салыстыру → екіге бөлу, процесс → схема), аниматик, музыка дыбысы бәсеңдейді, bordeaux стилі | смысловой каркас, драматургия, сапа рубрикасы, стыктарды тексеру, анимация режиссурасы |
| Жетіспейтіні | сұрақтар жоқтың қасы, раскадровкада «не айтылады / кадр ішінде не өзгереді / өту» жоқ, анимация әлсіз | сол сияқты; 11 skill бір-бірін қайталайды | Remotion/монтажға байланбаған, бекіту міндетті емес, музыканы өзі жасайды, суретке API кілт керек |
| Қайталау | сұрақ ережесі, бекіту ережесі, дыбыс/музыка ережесі 3–4 файлда | «процесс» тізімі SKILL.md мен editorial-motion екеуінде | QC — екі skill-де де |
| Қайшылық | — | — | «музыканы өзі жаса» ↔ «тек пайдаланушының музыкасы»; «аралық бекіту міндетті емес» ↔ «бекітусіз рендер жоқ»; HTML/CSS таймлайн ↔ Remotion |

## Неден не алынды
- **1-ден:** бекіту гейті, тек өз дауысы, QC + SendUserFile, обложка, қауіпсіз аймақтар, команда ретi.
- **2-ден:** мағына → кадр кестесі, `directions.json`, аниматик, музыка дакингі, дыбыс ережелері, «тек аудио → толық анимация».
- **3-тен:** смысловой каркас (крючок → механизм → дәлел → қорытынды), бір сквозная идея, оқу терезесі, сапа рубрикасы, персонаж карточкасы — `references/animation.md`. Музыка генерациясы мен «бекітусіз» ережесі алынбады.
- **Жаңа:** 2–3 сұрақ банкі мен шаблоны, `voice-script` (дауысқа мәтін + жазуды сұрау), `shotlist.md` (әр кадр: уақыт, экран, сөз, мәтін, кадр ішіндегі өзгеріс, өту), `scene` (N-кадрды өзгерту), «Монтажды бастау / Кадрды өзгерту», `pptx` (қосымша), субтитрлердің қабаттасуын тексеру.
- 10 бөлек skill → 1 `SKILL.md` + 10 `references/*.md` (әр тақырып бір жерде).
