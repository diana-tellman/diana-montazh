# DIANA MOBILE MOTION STUDIO — правила для Claude

Система storyboard-first видеомонтажа на Remotion для учеников, работающих с iPhone через Claude Code.
Архитектура: `docs/ARCHITECTURE.md`.

## Главный принцип для пользователя
Ученик делает только пять вещей: **загружает материалы → пишет пожелания по стилю → смотрит сториборд → одобряет или просит правки → получает MP4 и обложку.**
Все технические шаги (установка зависимостей, загрузка моделей, команды `npm run …`) выполняет Claude сам. Не просить ученика ничего устанавливать или настраивать.

## Процесс
ANALYSIS → STORYBOARD → APPROVAL → RENDER → COVER → QUALITY CONTROL → DELIVERY.

- **Никогда не рендерить финал без явного одобрения актуальной версии сториборда.** Существенная правка после одобрения снимает одобрение.
- Обложка — только после успешного финального рендера.
- Не выдавать незавершённые функции за работающие. Если что-то определено только по звуку или метаданным — так и сказать.
- «Файл готов» — только когда файл создан, проверен ffprobe и реально отправлен пользователю.

## Голос — только собственный голос пользователя
- Озвучка видео = голос пользователя: речь из его видео или его аудиозапись (MP3/M4A/WAV).
- **Никакого синтеза речи, TTS, клонирования или замены голоса.** Если голосовой записи нет — попросить загрузить её.
- Обработка голоса только корректирующая (гул, шум, свистящие, громкость); тембр не меняется.

## Режимы (определяет `npm run new`, код `src/core/modes.ts`)
- **expert-video** — видео с речью пользователя.
- **voice-over-visuals** — аудиозапись пользователя + фото/видео без речи (или только анимационная графика).
- Если неясно, какая запись — голос, скрипт возвращает код 3 и вопрос: задать его пользователю дословно.

## Распознавание речи
- `npm run transcribe -- <id>` — локально (sherpa-onnx + Whisper large-v3-turbo + Silero VAD). Модели скачиваются автоматически с официальных релизов GitHub и проверяются по SHA-256. Первая загрузка ~564 МБ.
- Если пользователь дал текст сценария — субтитры берут **точные слова сценария**, а время — из записи.
- Распознанный текст всегда показывать в сториборде для проверки (особенно казахский).
- Если распознавание недоступно — импорт SRT/VTT или текста с таймкодами (`--import`).
- Тайминг фраз измерен по аудио; тайминг отдельных слов — оценочный. Так и сообщать.

## Данные и безопасность
- Материалы пользователей лежат в `projects/` и **никогда не коммитятся**; модели — в `models/` (тоже не коммитятся).
- Не использовать личные секреты, глобальные Skills, непроверенные сторонние скрипты и платные сервисы без согласия.
- Перед разрушительными изменениями — резервная ветка.

## Команды (выполняет Claude)
- `npm ci` — если нет `node_modules`.
- `npm run doctor` — что работает в текущем окружении.
- `npm run new -- [--name <имя>] [--style "<пожелания>"] [--lang kk|ru|en] [--voice <файл>] [--script <txt>] <файл> [<файл> …]`
- `npm run transcribe -- <id> [--import <srt|vtt|txt>]`
- `npm run status -- <id>`
- `npm test`, `npm run typecheck`, `npm run smoke`
