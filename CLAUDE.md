# DIANA MOBILE MOTION STUDIO — правила для Claude

Система storyboard-first видеомонтажа на Remotion. Пользователи работают с iPhone через Claude Code.
Архитектура: `docs/ARCHITECTURE.md`.

## Главный процесс (для всех режимов)
ANALYSIS → STORYBOARD → APPROVAL → RENDER → COVER → QUALITY CONTROL → DELIVERY.

- **Никогда не рендерить финал без явного одобрения актуальной версии сториборда.** Любая существенная правка после одобрения снимает одобрение.
- Обложку делать только после успешного финального рендера.
- Не выдавать незавершённые функции за работающие. Если анализ сделан только по звуку/метаданным — так и сказать.
- Не говорить «файл готов», пока он не создан, не проверен ffprobe и реально не отправлен пользователю.

## Режимы (определяет `npm run new`, код: `src/core/modes.ts`)
- **expert-video** — своё видео с речью: оригинальный голос сохраняется.
- **text-to-video** — по тексту: TTS-диктор (после одобрения сториборда) или загруженная озвучка.
- **audio-to-video** — своя аудиозапись: анимация под оригинальный голос.
- Если неясно, сохранять ли голос, — спросить пользователя (скрипт вернёт exit code 3 и вопрос).

## Голос
- Не заменять голос реального человека без его явного согласия (`--consent-replace-original`).
- Клонирование голоса запрещено.
- Платный TTS не обязателен и без согласия владельца не подключается.
- Черновой голос eSpeak — только для тайминга превью; в финал — только с согласия.

## Данные и безопасность
- Видео/аудио пользователей лежат в `projects/` и **никогда не коммитятся**.
- Не использовать личные секреты, глобальные Skills и сторонние непроверенные скрипты.
- Вся логика — в `src/` и `scripts/`; Skills вызывают `npm run …` и читают JSON-вывод.

## Команды
- `npm run doctor` — что работает в текущем окружении.
- `npm run new -- --name <имя> --request "<слова пользователя>" [--file <видео|аудио>] [--script <txt>] [--voiceover <аудио>] [--lang kk|ru|en]`
- `npm run status -- <id>`
- `npm run voice -- list|check|download|use|set|preview|synth …`
- `npm test`, `npm run typecheck`, `npm run smoke`
