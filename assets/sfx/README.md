# Өз дыбыстарыңыз / Свои звуки

Мұнда өз лицензияңыз бар дыбыстарды салсаңыз (мысалы, Artlist / Motion Array пакеті), жүйе стандартты дыбыстардың орнына соларды қолданады.
Файл атауы — дыбыс атымен бірдей: `whoosh.wav`, `swipe.mp3`, `pop.wav`, `impact.wav`, `click.wav`, `sweep.wav`, `tonal.wav`, `trace.wav`, `tick.wav`, `soft.wav`, `riser.wav`, `reveal.wav`, `type.wav`, `bell.wav`.

⚠️ Ақылы пакеттердің лицензиясы әдетте басқаларға таратуға рұқсат бермейді — оларды шаблонға салмаңыз, әр оқушы өз көшірмесіне өзі қосады.

Стандартты дыбыстар: `uisfx` (CC0, қоғамдық игілік) + синтезделген қабаттар.
