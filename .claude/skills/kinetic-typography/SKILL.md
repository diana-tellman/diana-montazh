# Kinetic Typography

Код: `src/design/styles.ts`, `src/design/fonts.ts`, `src/compositions/Edit.tsx`.

| Стиль | Характер | Шрифт |
|---|---|---|
| `brand` (по умолчанию) | графит/бордо/белый, активное слово на бордовой плашке | Onest 800 |
| `minimal` | спокойный белый, золотой акцент | Inter 700 |
| `kinetic` | капс, слова выпрыгивают, красная плашка, без обводки | Montserrat 900 |
| `glass` | стеклянная плашка iOS, слова поднимаются | Onest 700 |
| `lime` | стикер: чёрный капс на лайме | Montserrat 900 |
| `editorial` | премиум-постер: молочный/розовый, акцентные слова курсивом Cormorant | Inter Tight 800 |

Роли шрифтов в каждом стиле: субтитры (`font`), заголовки карточек/плашки/слово за головой (`titleFont`: Inter Tight, Montserrat, Geologica), акцентная строка (`accentFont`: курсив Cormorant, Bad Script).

- Шрифты встроены в репозиторий (npm @fontsource, OFL) и проверены по таблице символов на **Ә Ғ Қ Ң Ө Ұ Ү Һ І**: Onest, Inter, Inter Tight, Montserrat, Geologica, Rubik, Raleway, Nunito, Oswald, PT Serif, Cormorant Garamond, Bad Script. Нельзя (нет казахских букв): Manrope, Unbounded, Bebas Neue, Dela Gothic One, Great Vibes, Marck Script.
- Цвета пользователя всегда важнее палитры стиля. Тёмный акцент (бордо) показывается маркером под словом, а не цветом текста — иначе нечитаемо на видео.
- Акценты: `*слово*` в сценарии, числа — автоматически; иначе система сама выбирает одно длинное слово примерно в каждой третьей фразе.
- **Слово за головой** — крупное слово (≤12 букв) за силуэтом человека, ~1 раз на 15 с, только если над головой есть место. Силуэт вырезается MediaPipe по кадрам при рендере.
- Размер субтитров стандартный для Reels: ~48–56 px при ширине 1080. Обводку (stroke) не использовать — только мягкая тень.
- Позиция по умолчанию — внизу, сразу над «слепой» зоной интерфейса; выше — только если внизу мешает лицо.
- Межстрочный интервал 1.0–1.12, ≤2 строк, строки сбалансированы, без «висячих» слов. Строка, которая не помещается, автоматически ужимается в браузере.
