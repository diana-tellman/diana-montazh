# Storyboard Builder

Источник правды — `projects/<id>/storyboard/storyboard.json` (схема: `src/storyboard/schema.ts`).
После ЛЮБОЙ правки: `npm run storyboard -- <id>` (версия увеличится, одобрение снимется) → показать contact-sheet.jpg → ждать нового одобрения.

## Глобальные правки — перепланировать с опциями (`npm run plan -- <id> …`)
| Просьба | Опция |
|---|---|
| другой стиль / «динамичнее» | `--style kinetic` / `--energy 2` |
| «текст красный и белый» | `--text white --accent red` (цвета: названия kk/ru/en или HEX) |
| «текст выше / ниже / по центру» | `--position top|bottom|middle` |
| «убери слово за головой» | `--no-behind` |
| «без звуков» / «без полоски» | `--no-sfx` / `--no-progress` |
| «для ленты / ютуба» | `--format 4:5` / `--format 16:9` |
Опции запоминаются в `storyboard/options.json` — повторять не нужно.

## Точечные правки — редактировать storyboard.json
- **Текст слова**: `captions[i].lines[l][w].text` (тайминг не трогать).
- **Акцент**: `emphasis: true/false` у слова.
- **Размер одного субтитра**: `captions[i].scale` (0.72–1.4). **Позиция**: `captions[i].y` (0..1 от верха).
- **Слово за головой**: `behindText[]` — изменить `text`, удалить элемент.
- **Плашка/CTA**: добавить в `callouts[]` `{id, start, end, text, kind: "glass"|"tag"|"cta", y}`.
- **Звук**: удалить/добавить в `sfx[]`.
Сцена N в сториборде = `scenes[N-1]` с границами `start..end` — правь элементы, попадающие в этот интервал.

## Проверки
`npm run storyboard` пересчитывает проверки. Если появилась ошибка «перекрывает лицо» или «вне безопасной зоны» — сам исправь (`y`, `scale`, или `--position`), не показывай пользователю сломанный вариант. Если места нет — предложи другой layout словами.
