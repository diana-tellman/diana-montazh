# Render & Quality Control

1. `npm run approve -- <id>` — только после явного одобрения пользователем текущей версии.
2. `npm run render -- <id>` (длинное видео — в фоне). ~2.5–3 мин рендера на минуту видео. Без одобрения актуальной версии рендер откажется работать — это правильно, не обходить.
3. `npm run cover -- <id> …` (skill `cover-generator`).
4. `npm run qc -- <id>` → `output/quality-report.md`. Автоматически: соответствие одобренной версии, текст не на лице и в безопасной зоне, H.264/yuv420p, разрешение, fps, длительность = голос, AAC 48 кГц, BT.709, faststart, −14 LUFS, пики, клиппинг, обложка.
5. Обязательно посмотри `output/qc-frames.jpg` (Read): текст читается, не обрезан, не на лице.
6. Выдача: SendUserFile `output/final-video.mp4` и `output/cover.png`. Если файл не дошёл — `npm run render -- <id> --max-mb 90` и повторить.
7. Если что-то из QC не прошло — исправь и повтори; пользователю сообщи честно, что было исправлено. Пункты «требует просмотра» перечисли.
