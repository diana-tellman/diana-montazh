# Motion Graphics

Код: `src/plan/planner.ts` (камера, сцены), `src/compositions/Edit.tsx`.

- **Камера (expert-video)**: планы делятся по склейкам исходника и паузам каждые ~3.5 с; зум чередуется 1.0 / 1.12 / 1.04 / 1.16 (jump-cut зум), на акцентной фразе длинного плана — плавный наезд 0.9 с. `--energy 0` — статично, `2` — энергичнее.
- **Фото (voice-over-visuals)**: равные отрезки по границам фраз, медленный наезд Ken Burns.
- **Только голос**: анимированный градиентный фон в цветах бренда + крупные субтитры.
- **Макеты** (`layouts` в storyboard.json, опция `--layout`):
  - `full` — человек на весь кадр (по умолчанию);
  - `circle` — человек в круге с белой рамкой поверх фото/клипа/фона бренда («адамды шеңберге салу»);
  - `split` — экран делится: сверху фото/видео, снизу человек, между ними акцентная линия;
  - `auto` — если ученик прислал к своему видео дополнительные фото/клипы, система сама вставляет моменты split-screen (≈1 на фото, 2.5–4.5 с, границы совпадают с субтитрами).
  - Отрезок вручную: добавить в `layouts[]` `{id, start, end, kind, secondary, secondaryKind, secondaryW, secondaryH}` и `npm run storyboard`.
- **Иконки по смыслу** (`icons[]`, `src/design/icons.ts`): своя библиотека линейных иконок (телефон, деньги, время, идея, галочка, сердце, звезда, рост, видео, чат, колокольчик-подписка, внимание, огонь, цель, книга, подарок, ссылка, глаз). Появляются, когда звучит слово-ключ (kk/ru/en), рисуются линией, «выпрыгивают» со звуком pop, не чаще 1 раза в 3.5 с, никогда не на лице и не на субтитре. Нет места — иконка не ставится. Выключить — `--no-icons`; убрать одну — удалить из `icons[]`; добавить — вписать `{id, start, end, name, x, y, size: 0.17, word}`.
- **Плашки** (`callouts`): `glass` — стекло, `tag` — белый ярлык, `cta` — кнопка с мягким свечением. Добавлять по просьбе или в финальной фразе с призывом.
- **Производительность**: размытие/цветокоррекцию делает ffmpeg заранее. Не добавлять CSS `filter: blur()` на полноэкранное видео (в облаке без GPU — в 3 раза медленнее).
