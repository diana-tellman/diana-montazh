# Cover Generator

`npm run cover -- <id> --title "Короткий *заголовок*" [--word СӨЗ] [--tag "Сабақ 1"] [--t <сек>] [--no-word]`

- Только после `npm run render` (скрипт проверяет статус).
- Кадр выбирается автоматически: крупное лицо по центру, рот закрыт, резкость. Лицо **никогда не генерируется** — только реальный кадр. Другой кадр — `--t`.
- **Заголовок придумай сам** по смыслу ролика: 2–6 слов, на языке ролика, одно ключевое слово в `*звёздочках*` (акцент). Сначала предложи 2 варианта пользователю, если он не просил иначе.
- Заголовок держится внутри центральной 3:4 области — сетка профиля Instagram его не обрежет. Превью сетки: `output/cover-grid-preview.jpg`.
- Посмотри `output/cover.png` сам (Read) перед отправкой.
