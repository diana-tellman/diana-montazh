# Editorial Motion — монтаж по смыслу

Принцип: **слова управляют кадром.** Один смысловой момент = один главный приём, в момент произнесения своего слова. Сначала смысл, потом дизайн. Содержание (речь, лицо, подписи) — только из материалов пользователя.

## 1. Таблица решений
| Что говорит спикер | Как строится кадр | В коде |
|---|---|---|
| эмоция («керемет!», «шынымен», «!») | спикер на весь кадр, плавный наезд на лицо 0.6 с | `emotion` → камера |
| пример («мысалы», «например») | спикер переезжает в окно сверху (скруглённое / круг), ниже — карточка примера или присланное фото/клип | layout `pip` |
| сравнение («X емес, Y», «или», «vs», «бұрын/қазір») | сверху А │ VS │ Б, снизу спикер | layout `compare` |
| процесс («алдымен… содан кейін… соңында», «шаг») | спикер уходит (круговое раскрытие), голос продолжается; шаги появляются на своих словах | layout `explainer`: `steps` или `flow` (узлы + кривые) |
| перечисление («субтитр, иконкалар, анимациялар») | центр + спутники, каждый вылетает на своём слове | explainer `orbit` |
| число («10 минут», «8 жыл», «87%») | БОЛЬШОЕ число со счётом 0 → N (за головой / над / под подбородком); аудитория ≥ 100 → стеклянный счётчик, % → кольцо, время → таймер | poster `count`, widget `counter/ring/timer` |
| Instagram / подписчики · поиск · «қос» · «пікірге жаз» | стеклянные виджеты у спикера: уведомление, строка поиска с набором, переключатель, поле комментария | widgets |
| начало ролика (хук), `*акцент*` | постер: маленькая строка + БОЛЬШОЕ слово (за головой, если есть место) + рукописная строка | poster (`behindText` + `label/script`) |
| главная мысль («ең бастысы», «главное») | стеклянная плашка; эти слова уходят из субтитров | callout `glass` |
| призыв («жазылыңыз», «пікірге жаз») | кнопка с мягким свечением | callout `cta` |
| вопрос / обычная речь | спикер на весь кадр | — |

Смысл читается **по предложениям** (`sentencePhrases`), независимо от того, как нарезаны субтитры. Всё, что сказано на экране плашкой/постером, из субтитров убирается (без дублей).

## 2. Два режима
**Только АУДИО (голос без видео и фото)** → полноценное объясняющее видео: каждое предложение — своя карточка, без пустого фона. Смысловые моменты → пример / сравнение / поток (≤ 3 шагов) / шаги / орбита / счётчик; остальное → заголовок: маленькая строка + БОЛЬШОЕ ключевое слово (`*акцент*`, иначе существительное, не глагол) + рукописный хвост + иконка. Соседние карточки сменяются без «круга». Правила темпа не действуют.

**Эксперт в кадре** → лицо главное. Макеты ≤ 50 % времени, первые 1.2 с — всегда лицо, между макетами ≥ 2 с, каждый ≥ 1.6 с (процесс до 9 с). Между ними — постеры, плашки, виджеты вокруг лица (никогда на лице и на субтитрах).

## 3. Стиль `bordeaux` (по умолчанию из `менің-талғамым.md`) — `--style bordeaux`
Взят из трёх референсов пользователя (тёмный explainer, эксперт со стеклянными виджетами, светлые схемы с красными узлами):
- **Субтитры** — как в референсе 3: **одно слово** за раз, жирный геометрический **Montserrat Alternates 800** (Λ-образные «л», «д»), строчные, плотный трекинг, **без анимации — жёсткая смена слова**. На видео белые с мягкой тенью, на светлой панели — чёрные. `*Акценты*` розовые (#F4A6C0) на видео, бордо (#9B1C40) на светлом. Высота ≈ 66 % (на уровне груди).
- **Постеры** — тонкая строка над БОЛЬШИМ узким словом **Oswald** бордо, рукописная строка **Bad Script**, наклон −3°; числа считают.
- **Схемы** — светлая панель (#F4F1EE) с точечной сеткой, **глянцевые бордовые карточки** (градиент + блик сверху + мягкая цветная тень), белые значки, чёрные подписи. Это не «стекло» — стекло только у виджетов поверх видео.
- **Виджеты на видео** — тёмное стекло, бордовые значки, розовые детали.

Другие стили: `brand`, `minimal`, `kinetic`, `glass`, `lime`, `editorial` (Inter Tight + курсив Cormorant). Слова пользователя важнее стиля.

## 4. Процесс (Claude)
1. **Текст.** Казахский распознаётся с ошибками → предложи исправленный текст одним сообщением (с `*акцентами*` на 3–6 ключевых словах, включая многословные: `*Claude Code*`, `*8 жыл*`) и спроси фамилию/термины, музыку, заголовок обложки. Сохрани как `script.txt`, пропиши `scriptFile` в `project.json`, `npm run transcribe -- <id>` (смотри `matchRatio`: ≥ 0.7 — норма).
2. `npm run plan -- <id> --style bordeaux` → прочитай `work/beats.json` (предложения с временем + автоматические решения).
3. **Проверь смысл сам** и при необходимости запиши `storyboard/directions.json`, затем снова `plan`. Времена — точные из `beats.json`/транскрипта: Claude-биты держат **точный интервал**, а не всё предложение (два приёма в одном предложении не мешают друг другу):
   ```json
   { "replaceAuto": true, "beats": [
     { "start": 4.6,  "end": 6.8,  "intent": "key", "plate": "Диана Тиллман" },
     { "start": 10.45, "end": 14.3, "intent": "process", "variant": "flow", "items": ["зерттеп", "қарастырып", "үйренетін боламыз"] },
     { "start": 14.7, "end": 19.9, "intent": "key", "plate": "Шымкент → Алматы" },
     { "start": 20.2, "end": 21.8, "intent": "number" },
     { "start": 21.85, "end": 25.95, "intent": "example", "items": ["Инфобизнес"], "shape": "rounded" },
     { "start": 26.0, "end": 31.7, "intent": "list", "items": ["Мобилограф", "SMM", "контент-продюсер", "жасанды интеллект"] } ] }
   ```
   intent: `emotion | example | compare | process | list | number | key | cta | question | neutral`; `variant`: `steps | flow | orbit | counter | headline | example | compare`. Подписи — 1–3 слова **из речи спикера**. Образец: `example-directions.json`.
4. **Крупное лицо** (подбородок ниже ~55 % кадра): опусти субтитры, чтобы между лицом и субтитром было место для плашек и постеров — `styleOverrides.preferY: 0.71` в `storyboard/options.json`, затем `plan`. Постер под подбородком сам уменьшается до свободной полосы.
5. `npm run storyboard -- <id>` → **посмотри contact-sheet сам**: карточка/плашка не на лице и не на субтитре, текст влезает, окно не режет голову, субтитры по одному слову, без «*». Ошибки исправь до показа.
6. `npm run animatic -- <id>` (≈ 70–90 с на 35 с) → кадры в моменты переходов посмотри сам (`ffmpeg -ss <t>`), затем отправь пользователю **animatic.mp4 + contact-sheet.jpg + storyboard.html** и коротко таблицей: время → что говорит → что в кадре. Спроси одобрение.
7. Только после «мақұлдаймын / ок» → `approve` → `render` → `cover` → `qc` (skill render-quality-control).

## 5. Звук (правила измерены на референсах)
- **Только аудио**: ≈ 1 звук в секунду, ровно на каждом появлении (задержка ≈ 0).
- **Эксперт**: редко (≈ 1 на 3 с), только на графике, ≈ 0.1 с после начала движения; обычные склейки — без звука.
- **Смена сцены**: whoosh начинается ≈ 0.15 с **до** перехода.
- Соответствие: макет → `whoosh`, соседние схемы → `swipe`, шаг/узел → `click`, карточка/кнопка/иконка → `pop`, второй пункт сравнения → `impact`, плашка → `soft`, набор текста → `type`, уведомление → `ding`, счёт → `tickroll`. Gain 0.13–0.2 (предупреждение > 0.35).
- **Музыка** — только присланная пользователем: `--music <файл>`; −18 LUFS, под речью ×0.07 (≈ на 19 дБ тише голоса), в паузах ×0.2, переходы 0.25 с. Если в видео музыка уже есть — свою не добавлять.

## 6. Типографика и безопасность
- Все шрифты проверены по таблице символов на **Ә Ғ Қ Ң Ө Ұ Ү Һ І**: Onest, Inter, Inter Tight, Montserrat, **Montserrat Alternates**, Geologica, Rubik, Raleway, Nunito, Oswald, PT Serif, Cormorant Garamond, Bad Script. Нельзя: Manrope, Unbounded, Bebas Neue, Dela Gothic One, Great Vibes, Marck Script.
- Кнопки Instagram справа внизу: ниже 62 % высоты правый край текста ≤ 82 % ширины. Лицо защищено (овал + волосы, от макушки до подбородка) для субтитров, карточек, плашек, виджетов — проверяется автоматически.

## Чего не делать
- Не закрывать лицо, не дублировать плашку/постер субтитром.
- Не придумывать реплики и подписи, не менять голос и длительность, никакого TTS.
- Не ставить приём на каждую фразу у эксперта: 3–6 смысловых приёмов на 30 с.
- Не рендерить без одобрения актуальной версии, не говорить «готово» без QC и отправки файлов.
