# Editorial Motion — монтаж по смыслу

Принцип: **слова управляют кадром.** Один смысловой момент = один главный приём. Сначала смысл, потом дизайн.

## Таблица решений
| Что говорит спикер | Как строится кадр | Код |
|---|---|---|
| эмоция («керемет!», «шынымен», «невероятно», «!») | спикер на весь кадр, плавный наезд на лицо 0.6 с | `emotion` → камера |
| пример («мысалы», «например», «for example») | спикер переезжает в окно сверху (скруглённое / круг, чередуются), ниже — карточка примера (слово + иконка) или присланное фото/клип | layout `pip` |
| сравнение («X емес, Y», «или», «vs», «бұрын/қазір», «сравним») | экран делится: сверху карточки А | VS | Б, снизу спикер | layout `compare` |
| процесс («алдымен… содан кейін… соңында», «шаг», «сначала… затем») | спикер временно уходит (круговое раскрытие), полноэкранная схема: шаги с иконками и линией, каждый шаг — в момент, когда он произнесён | layout `explainer` |
| главная мысль («ең бастысы», «главное», «запомни») | стеклянная плашка над головой; эти же слова убираются из субтитров | callout `glass` |
| призыв («жазылыңыз», «пікір жаз», «сохрани») | кнопка с мягким свечением | callout `cta` |
| вопрос / обычная речь | спикер на весь кадр | — |

Правила темпа (в коде, `src/plan/director.ts`): первые 1.2 с — всегда лицо (хук); макет ≥ 1.6 с (обычно 2.4–6.5 с, процесс до 9 с); между макетами ≥ 2 с; макеты занимают ≤ 50 % ролика; границы совпадают с границами субтитров. Без видео спикера (голос + фото) все смысловые моменты — полноэкранные схемы.

## Процесс (Claude)
1. `npm run plan -- <id> …` → в выводе `layouts`, `beats`, `plates`. Полный список фраз с временем и автоматическими решениями — `work/beats.json`.
2. **Прочитай `work/beats.json` и проверь смысл сам.** Автоматика ищет слова-маркеры; ты понимаешь смысл. Исправь, если:
   - процесс/сравнение/пример есть по смыслу, но без маркера (или маркер сработал ложно);
   - на карточке не те слова (подписи — 1–3 слова **из речи спикера**, ничего не выдумывать);
   - референс или пожелание просит другой ритм («больше схем», «без окон»).
   Тогда запиши `storyboard/directions.json` (образец рядом: `example-directions.json`) и снова `npm run plan -- <id>`:
   ```json
   { "replaceAuto": false,
     "beats": [ { "start": 22.4, "end": 27.0, "intent": "compare", "reason": "телефон vs компьютер", "items": ["Телефон", "Компьютер"] },
                { "start": 13.3, "end": 21.9, "intent": "process", "title": "3 қадам", "items": ["Жүкте", "Стиль жаз", "Дайын видео"] },
                { "start": 5.2, "end": 7.7, "intent": "example", "items": ["Кофехана"], "shape": "circle" } ] }
   ```
   `replaceAuto: true` — только твои решения; `false` — твои важнее, автоматика заполняет остальное. Времена бери из `work/beats.json` (они привязываются к границам фраз, а время появления каждого пункта — к моменту, когда это слово произнесено).
3. `npm run storyboard -- <id>` → **посмотри contact-sheet сам**: карточка не на лице и не на субтитре, текст читается, окно со спикером не обрезает голову. Ошибки исправь до показа.
4. `npm run animatic -- <id>` (≈1.5 мин на 35 с) → `storyboard/animatic.mp4` 540p с водяным знаком «ЭСКИЗ»: движение, переходы, звук и музыка. Отправь вместе со сторибордом — по картинкам переезд в окно и схему не понять.
5. Одобрение → `approve` → `render` → `cover` → `qc` (skill render-quality-control).

## Типографика
Роли (`src/design/styles.ts`): субтитры — `font`; карточки, плашки, слово за головой — `titleFont`; акцентная строка — `accentFont` (курсив). Все шрифты проверены по cmap на **Ә Ғ Қ Ң Ө Ұ Ү Һ І**:
Onest, Inter, **Inter Tight**, Montserrat, **Geologica**, Rubik, Raleway, Nunito, Oswald, PT Serif, **Cormorant Garamond** (курсив), **Bad Script** (рукописный).
Нельзя (нет казахских букв): Manrope, Unbounded, Bebas Neue, Dela Gothic One, Great Vibes, Marck Script.
- Стиль `editorial` (`--style editorial`): Inter Tight 800 + акцентные слова курсивом Cormorant, молочный #F7F5F2 / розовый #F2D5E4, мягкое появление снизу. Для «премиум», «как у дизайнеров», «журнальный».
- Референс: классы шрифтов в `reference-style.json` — плюс `tight-display`, `soft-geometric`, `editorial-serif`, `script`.
- Субтитры у кнопок Instagram (низ справа, ниже 62 % высоты) автоматически уже: правый край ≤ 82 % ширины.

## Звук
- Каждый звук — к конкретному появлению, в его момент: макет → `whoosh`, схема → `swipe`, шаг схемы → `click`, карточка/кнопка → `pop`, второй пункт сравнения → `impact`, плашка → `soft`. Не чаще 1 раза в секунду, gain 0.14–0.2 (проверка предупредит, если > 0.35).
- Музыка: `npm run plan -- <id> --music <файл>` (только присланная пользователем или с понятной лицензией). Нормализуется до −18 LUFS, под речью приглушается до 0.07 (≈ на 19 дБ тише голоса), в паузах 0.2, плавно (0.25 с). `--no-music` — убрать. Если в исходном видео уже есть музыка — свою не добавлять.

## Чего не делать
- Не закрывать лицо текстом/карточками (проверяется автоматически), не дублировать плашку субтитром (дубль убирается сам).
- Не придумывать реплики и подписи, не менять голос и длительность.
- Не ставить макет на каждую фразу: смысловых приёмов 2–5 на минуту.
- Не объявлять «готово» без сториборда + аниматика, одобрения, QC и отправки файлов.
