# Editorial Motion — как делать премиальный монтаж

Принцип: **слова управляют графикой.** Один смысловой блок = один главный приём. Сначала анализ речи, потом дизайн.

## Процесс
1. `npm run new …` (материалы) → `npm run plan -- <id>` (транскрипт + лица).
2. Если есть референсы (видео и/или картинки): `npm run reference -- <id> <файлы…>` → смотри `work/reference/frames.jpg`, переноси приёмы (шрифтовые роли, композицию, цвета, движение) в beats.json.
3. Стартовый план: `npm run beats-template -- <id>` → `storyboard/beats.json` (по одному постеру на фразу). **Перепиши его по смыслу** (см. правила ниже). Образец готовой работы: `example-beats.json` рядом с этим файлом.
4. `npm run plan -- <id> --beats --style editorial [--sfx-theme cinematic]`.
5. `npm run storyboard -- <id>` + `npm run keyframes -- <id> <t1> <t2> …` (кадры в моменты акцентов). **Посмотри сам**, исправь: текст не на лице, акцент не закрывает буквы, голова не прячет главное слово.
6. **`npm run animatic -- <id>`** → отправь пользователю превью движения и звука (540p, ~1 мин рендера). Без него не проси одобрение премиального монтажа.
7. Одобрение → `approve` → `render` → `cover` → `qc` (skill render-quality-control).

## Дизайн-система (по умолчанию; цвета/шрифты пользователя важнее)
| Роль | Шрифт (все с Ә Ғ Қ Ң Ө Ұ Ү Һ І) | Для чего |
|---|---|---|
| `sans` | Inter Tight 900, трекинг −0.045em | главное слово, крупно |
| `serif` | Cormorant Garamond 600 | спокойная вторичная строка |
| `italic` | Cormorant Garamond 700 italic | элегантный акцент, пересекает крупную строку |
| `script` | Bad Script | рукописный акцент, вопросы, короткие пометки |
| `label` | Inter Tight 700, КАПС, трекинг 0.18em | маленькая строка сверху/снизу |
Цвета: milk #F7F5F2, pink #F2D5E4 (главные слова), burgundy #8D263E (тонкие детали), graphite #191919. Нет обводки, неона, случайных цветных плашек.
Шрифты без казахских букв (Bebas Neue, Dela Gothic One, Great Vibes, Marck Script, Playfair, Manrope, Unbounded) — не использовать.

## Постер (`kind: "poster"`)
- Не задавай `y` — **стек-движок** сам измерит текст и соберёт композицию: одинаковый интерлиньяж, акцент italic/script слегка пересекает строку выше, всё влезает в `maxWidth` (по умолчанию 0.74 ширины).
- `anchorY`: центр композиции. Над головой — 0.13–0.18 (+ `behind: true`, чтобы человек был перед текстом; верх головы должен закрывать максимум треть второй строки). Под подбородком — 0.6–0.7 (+ `bg: "shade-bottom"`).
- Иерархия: 2–4 строки. `label` (маленькая) → `sans` (огромная) → `italic`/`script` (акцент) → `sans`/`label`. Не все три шрифта в каждом постере.
- `bg`: `none` · `shade-top` · `shade-bottom` · `mono` (ч/б версия видео) · `texture` (графитовая фактура, текст — главный объект) · `blur-dim`.
- Анимации (`anim`): `mask` (выход из маски), `stagger` (по буквам), `word` (по словам **в момент произнесения** — времена берутся из речи автоматически), `script` (рукописное проявление), `blur`, `scale` (типографический масштаб), `tracking` (сжатие трекинга), `slideLeft/Right`, `typewriter`, `fade`. Выход композиции (`exit`): `up` · `blur` · `fade` · `down` · `left` · `right`. `move` — редакционный сдвиг строки, когда появляется следующая. `underline: true` — прорисовка линии.
- `at` — точное время слова из транскрипта (`work/transcript.json`), не на глаз.
- Длительность: появление 0.3–0.6 с, удержание для чтения ≥ 0.8 с, выход 0.22 с. Предыдущая композиция полностью уходит до следующей.

## Остальные приёмы
- `cutout` — замена фона (`bg: texture|brand`), `compare` — до/после с разделителем, `outline` — белый контур вокруг человека (не вокруг текста).
- `layouts` → `split` (сверху графика, снизу человек), `pip` (человек в карточке), `circle`.
- `diagram` — узлы-иконки с прорисованными стрелками (иконки: `src/design/icons.ts`).
- `plate` — плашки: `glass`, `solid`, `outline`, `bracket` [ ], `tag`, `lowerThird`, `number`, `cta`, `quote`.
- `punch` — наезд камеры (ключи в `camera`) + световая полоса, `mono: true` — ч/б вспышка.
- `transition` — `type` (панель с огромным словом), `shape`, `flash`, `whip`, `zoom`. Под переходом смени композицию в его середине.
- Субтитры: только где нужны (`captionWindows`), стили `editorial` · `karaoke` · `bracket` · `boxed` · `typewriter` · `brand` · `minimal` · `glass` · `kinetic` · `lime`.

## Звук
- Названия: `whoosh` (крупный текст), `swipe` (смена фона, подчёркивания), `pop` (иконки, финальный акцент), `impact` (главное утверждение), `click` (UI, узлы), `sweep` (вырезание), `tonal` (script/вопрос), `trace` (контур), `tick`, `soft`, `riser` (перед главным моментом), `reveal`, `type`, `bell`.
- Источник: свой пакет в `assets/sfx/` → CC0 `uisfx` (тема `--sfx-theme`, послушать: `npm run sfx-demo -- <тема>`) → синтез.
- Каждый звук — к конкретному движению, в момент его пика. Не на каждое слово; оставляй паузы. Gain 0.5–0.85 (impact 0.5–0.75). После рендера проверь, что звуки слышны (сравни финал с голосом).

## Чего не делать
- Не закрывать лицо текстом (кроме `behind`, где лицо перед текстом).
- Не дублировать постер обычными субтитрами (слова постера убираются из субтитров автоматически).
- Не придумывать новые реплики, не менять голос и длительность.
- Не объявлять «готово» без animatic, одобрения, QC и отправки файлов.
