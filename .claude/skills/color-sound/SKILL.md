# Color & Sound

- **Цвет**: при подготовке ffmpeg переводит HDR (HLG/PQ, Dolby Vision iPhone) в SDR BT.709 мягким tone mapping (`mobius`), без пересыщения и резкости (`src/core/transcode.ts`). Цвет кожи не стилизуется.
- **Голос** (`src/audio/enhance.ts`): только коррекция — срез гула 70 Гц, лёгкое шумоподавление, де-эссер, мягкая компрессия, −16 LUFS. Тембр и высота не меняются. Голос никогда не заменяется.
- **Финал**: двухпроходная нормализация −14 LUFS, true peak ≤ −1 dBTP, проверка клиппинга в `npm run qc`.
- **Звуки** (`src/audio/sfx.ts`) — свои, синтезированные: `pop` (акцент), `whoosh` (слово за головой), `soft` (смена плана), `tick`, `riser`. Не чаще 1 раза в секунду, тише голоса. «Без звуков» → `--no-sfx`; убрать один — удалить из `sfx[]`.
