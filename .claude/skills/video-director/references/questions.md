# Уточняющие вопросы (этап 2)

Правило: **одно сообщение, 2–3 вопроса**, только те, что меняют результат и не видны из материалов / `менің-талғамым.md`. У каждого вопроса 2–3 варианта и твоя рекомендация (⭐). Если есть AskUserQuestion — задай через него (до 3 вопросов, рекомендованный вариант первым). Ответ «өзің шеш» = принимай рекомендации.

## Банк вопросов (выбери самые важные для этой задачи)
| Тема | Когда спрашивать | Варианты (рекомендация ⭐) |
|---|---|---|
| Для кого и зачем | идея размыта | жаңа клиенттер ⭐ / оқушылар / жазылушылар |
| Длительность | нет готовой записи | 15–20 с / 30–40 с ⭐ / 60 с |
| Формат | неясна платформа | Reels 9:16 ⭐ / YouTube 16:9 / лента 4:5 |
| Спикер в кадре | только идея | өзім түсірем (видео) ⭐ / тек дауыс → анимация / фото + дауыс |
| Голос | нет аудио | мәтінді мен жазып берем, сен оқисың ⭐ / өз мәтінің бар / дауыссыз (тек музыка+мәтін) |
| Текст сценария (kk) | казахская речь без текста | мәтінді жібер ⭐ / мен танып, тексеруге берем |
| Субтитры | не ясно из вкусов | бір сөзден ⭐ / 2–3 сөз / субтитрсіз |
| Музыка | ролик без музыки | өз MP3 жібересің / музыкасыз ⭐ / видеодағы музыка қалады |
| Стиль | нет референса и вкусов | bordeaux ⭐ / minimal / kinetic |
| Обложка | нужна | заголовок: 2 нұсқа ұсынам ⭐ / өзің жазасың |
| Референс неполный | часть не видна | осы жерін қалай жасаймыз — 2 варианта |

Голос без TTS: если голоса нет, вариант «синтез» **не предлагать**.

## Шаблон сообщения (kk)
```
Түсіндім: <1 сөйлеммен — не жасаймыз, қандай материалдан>.
Бастамас бұрын 3 сұрақ (жауап: «1-а, 2-б, 3-а» немесе «өзің шеш»):
1. Ұзақтығы? а) 15–20 с  б) 30–40 с ⭐  в) 60 с
2. Дауыс? а) мәтінді мен жазам, сен оқып жібересің ⭐  б) өз мәтінің бар
3. Музыка? а) өз MP3 жібересің  б) музыкасыз ⭐
```
