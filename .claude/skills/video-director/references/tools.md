# Инструменты студии: что, где, когда

Всё ставится само из репозитория: `npm ci` (Node-пакеты) и `npm run setup` (Python-среда + модели) — их вызывает скрипт облачной среды `setup/cloud-environment.sh`. Модели в git не кладутся: скачиваются при первом запуске и проверяются.

| Инструмент | Для чего | Где в проекте | Команда |
|---|---|---|---|
| **FFmpeg** | резка, перекодирование, HDR→SDR, громкость, кадры | предустановлен в облаке | внутри всех скриптов |
| **Whisper** (sherpa-onnx) + Silero VAD | распознавание речи kk/ru/en, время слов | `sherpa-onnx-node` в `package.json`, модели → `models/speech` | `npm run transcribe` (сам из `plan`) |
| **MediaPipe** | лицо, голова, силуэт **по кадрам видео** (текст за человеком, замена фона, контур) | `analysis/requirements.txt` | `analyze`, силуэт в `showcase`/`storyboard` |
| **rembg** | вырезать фон **одной картинки**: фото, обложка, кадр, предмет | `analysis/requirements.txt`, модель → `models/rembg` | `npm run cutout -- <фото|видео> [--t сек] [--model isnet-general-use] [--matting]` |
| **Remotion** | весь монтаж экспертного видео, анимация из голоса, постеры, рендер MP4 | `package.json` | `plan`/`storyboard`/`render`, `showcase` |
| **HyperFrames** (HeyGen, Apache-2.0) | чистая графика **без спикера**: заставка, логотип, кинетическая типографика, инфографика, анимация интерфейса | `package.json` (+ `gsap`) | `npm run hf -- new <папка>` → правка `index.html` → `npm run hf -- render <папка>` |

## Как выбирать
- Есть лицо/человек в видео → **Remotion** (`plan` или `showcase`): защита лица, силуэт, одобрение по хэшу, QC.
- Нужно вырезать человека/предмет на **фото** или **обложке** → **rembg** (`cutout`); на **видео по кадрам** → MediaPipe (быстрее на CPU).
- Только графика, без человека (интро 3–8 с, логотип, «карточка-заставка», UI-анимация) → **HyperFrames**. Готовый MP4 можно вставить в Remotion-монтаж как клип (`npm run new … <видео-со-спикером> <графика.mp4>`) или отдать отдельным роликом.

## Правила HyperFrames в этой студии
- Создавай проект только через `npm run hf -- new`: GSAP и шрифты с казахскими буквами кладутся рядом с `index.html` (облако без CDN), телеметрия выключена, используется предустановленный Chromium.
- Тексты — слова пользователя; палитра и шрифты — как в `editorial-style.md` (milk/pink/burgundy/graphite, Inter Tight, Cormorant italic, Bad Script).
- Каждый текстовый блок — один `class="clip"` с `data-start`/`data-duration`; строки внутри блока анимируются через GSAP по id (иначе клипы наложатся друг на друга).
- **Нельзя:** синтез речи/TTS (`synthesize`), `share`/`publish`, вход в аккаунт HeyGen, платные функции (`templates`, `billing`), внешние API-ключи. Голос — только пользователя.
- Порядок тот же: раскадровка (`npm run hf -- snapshot <папка> --at 1,2.5` → посмотри кадры сам) → «Монтажды бастау» → `render` → проверь MP4 (`ffprobe`, кадры) → отправь.
