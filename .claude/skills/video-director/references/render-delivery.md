# Рендер, обложка, проверка, выдача

1. `npm run approve -- <id>` — только после явного одобрения пользователем текущей версии.
2. `npm run render -- <id>` (длинное видео — в фоне). ~2.5–3 мин рендера на минуту видео. Без одобрения актуальной версии рендер откажется работать — это правильно, не обходить.
3. `npm run cover -- <id> …` (ниже).
4. `npm run qc -- <id>` → `output/quality-report.md`. Автоматически: соответствие одобренной версии, текст не на лице и в безопасной зоне, H.264/yuv420p, разрешение, fps, длительность = голос, AAC 48 кГц, BT.709, faststart, −14 LUFS, пики, клиппинг, обложка.
5. Обязательно посмотри `output/qc-frames.jpg` (Read): текст читается, не обрезан, не на лице.
6. Выдача: SendUserFile `output/final-video.mp4` и `output/cover.png`. Если файл не дошёл — `npm run render -- <id> --max-mb 90` и повторить.
7. Если что-то из QC не прошло — исправь и повтори; пользователю сообщи честно, что было исправлено. Пункты «требует просмотра» перечисли.

## Что проверить в готовом файле перед отправкой
- Файл открывается (`ffprobe`), H.264 yuv420p, AAC, faststart, размер кадра = формат (1080×1920 для 9:16), fps, длительность = голос.
- Текст читается на кадрах `qc-frames.jpg`: не обрезан, не на лице, не под кнопками Instagram, казахские буквы на месте.
- Звук совпадает с кадрами: приёмы стоят на своих словах (сверь 2–3 момента из `shotlist.md` кадрами `ffmpeg -ss <t>`); громкость −14 LUFS, без клиппинга. Слушать ты не можешь — скажи это и назови объективные проверки.
- Больше ~90 МБ или не дошёл → `npm run render -- <id> --max-mb 90` и отправь снова.

## Обложка (cover)

`npm run cover -- <id> --title "Короткий *заголовок*" [--word СӨЗ] [--tag "Сабақ 1"] [--t <сек>] [--no-word]`

- Только после `npm run render` (скрипт проверяет статус).
- Кадр выбирается автоматически: крупное лицо по центру, рот закрыт, резкость. Лицо **никогда не генерируется** — только реальный кадр. Другой кадр — `--t`.
- **Заголовок придумай сам** по смыслу ролика: 2–6 слов, на языке ролика, одно ключевое слово в `*звёздочках*` (акцент). Сначала предложи 2 варианта пользователю, если он не просил иначе.
- Заголовок держится внутри центральной 3:4 области — сетка профиля Instagram его не обрежет. Превью сетки: `output/cover-grid-preview.jpg`.
- Посмотри `output/cover.png` сам (Read) перед отправкой.
