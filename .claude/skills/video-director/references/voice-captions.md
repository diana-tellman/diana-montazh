# Голос, сценарий, субтитры

## Голос
- Только собственный голос пользователя: речь из его видео или его запись (MP3/M4A/WAV/видео). Никакого TTS/клонирования/замены. Обработка — только корректирующая (`src/audio/enhance.ts`: срез гула, лёгкое шумоподавление, де-эссер, компрессия, −16 LUFS; тембр не меняется).
- Несколько записей / неясно, что голос → `npm run new` вернёт код 3 с вопросом — задай дословно.

## Текст для записи (когда голоса нет)
1. Напиши текст по брифу: крючок в первой фразе, одна мысль на предложение, короткие предложения (≤ 12 слов), конкретика только из слов пользователя. Длина: kk ≈ 1.9, ru ≈ 2.2, en ≈ 2.5 слова/с (`wordsFor`). 3–6 ключевых слов в `*звёздочках*` (многословные тоже: `*Claude Code*`).
   Для анимации пиши маркерами смысла — по ним строится кадр: «мысалы…», «… емес, …», «алдымен… содан кейін… соңында…», числа цифрами, призыв в конце.
2. Сохрани `incoming/<имя>/script.txt` → `npm run voice-script -- incoming/<имя>/script.txt --lang kk --target 30 --title "…"`. `fits:false` → сократи/дополни.
3. Отправь `voice-script.md` (SendUserFile) **и** текст в чат; попроси прочитать и прислать запись. Жди файл.
4. Запись пришла → `npm run new -- … --script incoming/<имя>/script.txt <запись>` (субтитры = точный текст, время — из записи).

## Распознавание и субтитры
- Локально: Whisper large-v3-turbo + Silero VAD (sherpa-onnx), модели проверяются по SHA-256. `plan` вызывает `transcribe` сам.
- Казахский распознаётся хуже. Есть сценарий → всегда `--script`. Нет → предложи исправленный текст одним сообщением (с акцентами), спроси фамилии/термины, сохрани как сценарий, пропиши `scriptFile` в `project.json`, `npm run transcribe -- <id>` (`matchRatio` ≥ 0.7 — норма).
- Готовые субтитры: `npm run transcribe -- <id> --import file.srt|.vtt|.txt`.
- Исправление слова — правка `storyboard.json` (`captions[i].lines[l][w].text`), не перераспознавание.
- Время фраз измерено, время слов — оценка. Так и говори.
- Фразы ≤ 1–5 слов по стилю, разрыв на паузе ≥ 0.45 с, ≤ 2 строк.
