# Правки раскадровки («Кадрды өзгерту»)

Источник правды — `projects/<id>/storyboard/storyboard.json` (схема: `src/storyboard/schema.ts`).
После ЛЮБОЙ правки: `npm run storyboard -- <id>` (версия увеличится, одобрение снимется) → показать contact-sheet.jpg → ждать нового одобрения.

## Глобальные правки — перепланировать с опциями (`npm run plan -- <id> …`)
| Просьба | Опция |
|---|---|
| другой стиль / «динамичнее» | `--style kinetic` / `--energy 2` |
| «текст красный и белый» | `--text white --accent red` (цвета: названия kk/ru/en или HEX) |
| «текст выше / ниже / по центру» | `--position top|bottom|middle` |
| «убери слово за головой» | `--no-behind` |
| «без звуков» / «без полоски» | `--no-sfx` / `--no-progress` |
| «для ленты / ютуба / квадрат» | `--format 4:5` / `--format 16:9` / `--format 1:1` |
| «посади меня в круг» | `--layout circle` |
| «раздели экран на два» | `--layout split` (сверху — присланные фото/клипы) |
| «без иконок» | `--no-icons` |
| «премиум / как у дизайнеров» | `--style editorial` |
| «без окон и схем, просто я» | `--no-semantic` |
| «добавь музыку» (+ файл) / «без музыки» | `--music <файл>` / `--no-music` |
| «здесь схему / здесь сравнение / тут посади меня в круг» | `storyboard/directions.json` (`meaning-to-frame.md`) |
Опции запоминаются в `storyboard/options.json` — повторять не нужно.

## Точечные правки — редактировать storyboard.json
Сначала `npm run scene -- <id> <N>`: все элементы кадра N с путями (`captions[3]`, `layouts[1]`…) и его строка из `shotlist.md`.
- **Текст слова**: `captions[i].lines[l][w].text` (тайминг не трогать).
- **Акцент**: `emphasis: true/false` у слова.
- **Размер одного субтитра**: `captions[i].scale` (0.72–1.4). **Позиция**: `captions[i].y` (0..1 от верха).
- **Слово за головой**: `behindText[]` — изменить `text`, удалить элемент.
- **Плашка/CTA**: добавить в `callouts[]` `{id, start, end, text, kind: "glass"|"tag"|"cta", y}`.
- **Звук**: удалить/добавить в `sfx[]`.
- **Подпись на карточке схемы/сравнения/примера**: `layouts[i].card.items[k].text` (время `at` не трогать) — или правка в `directions.json` + `plan`.
- **Смысловой приём целиком** (убрать схему, заменить сравнение окном, добавить процесс) — только через `storyboard/directions.json` + `npm run plan` (так сохраняются границы субтитров и проверки).
Сцена N в сториборде = `scenes[N-1]` с границами `start..end` — правь элементы, попадающие в этот интервал.

## Проверки
`npm run storyboard` пересчитывает проверки. Если появилась ошибка «перекрывает лицо» или «вне безопасной зоны» — сам исправь (`y`, `scale`, или `--position`), не показывай пользователю сломанный вариант. Если места нет — предложи другой layout словами.

## Зависимые таймкоды
Время кадра меняется только через данные: границы макета (`layouts[i].start/end`), субтитры, `directions.json`. После `npm run storyboard` номера кадров, их границы, `shotlist.md`, contact-sheet и проверки пересчитываются из того же `storyboard.json` — покажи пользователю изменённый кадр и новые таймкоды соседних кадров. Длительность ролика = длительность голоса (не меняется правкой кадра).

## Как отвечать после правки
«3-кадр өзгерді: <что>. Жаңа уақыттар: 3 · 0:06–0:09, 4 · 0:09–0:12. Нұсқа v<N>.» + новый contact-sheet (и аниматик, если менялось движение) + снова «Монтажды бастау» / «Кадрды өзгерту».
