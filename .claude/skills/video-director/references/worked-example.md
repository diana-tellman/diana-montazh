# Полный пример: «Claude арқылы монтаж» (эксперт, 28.3 с, Premium Editorial)

Как образец для любого экспертного ролика по подробному брифу. Файлы проекта не в git; спецификация монтажа — `example-showcase.json`.

## 1. Изучить
- Ссылка Google Drive → `npm run fetch` → `.mov` HEVC 1080×1920 30 fps, 28.3 с (в брифе ошибочно «512×910» — сказали пользователю).
- `npm run study -- … --transcript …`: 3 плана (склейки 19.37 и 24.37 с), музыки нет (тишина в паузах), −20.6 LUFS, 9 пауз, 2.34 слова/с, пики движения 0.13 / 1.66 / 7.99 / 25.64 с. Поиск пика движения руки в окне 16.9–18.0 с → 17.53 с (место монтажной склейки «кадр ауысуы»).
- Бриф пользователя по секундам → `brief.md`.

## 2. Вопросы (одно сообщение, 3 пункта)
1) Исправленный текст речи (казахский распознан ~80 %: «Құлт» → «Claude») — «верно?». 2) Видео кончается через 0.3 с после последнего слова — добавить стоп-кадр 1.2 с? 3) Нужна ли обложка. Ответы: да / да / да.

## 3–4. Стиль и движок
Бриф требовал замену фона, контур, текст за человеком, комментарий-поле → **SHOWCASE**. Сценарий → `transcribe` (`matchRatio` 0.89) → точные времена слов. Силуэт на все 849 кадров (~4 мин). Проверка маски на цветном фоне (волосы, руки).

## 5–6. Раскадровка, версии
- v1–v2 — строго по брифу (бордо, Noto Sans): CLAUDE за головой, замена фона со шторкой, сдвиг фона (два слоя), контур, «Автоматты субтитр» + CC, МӘТІН, схема Кадр → Мәтін → Нәтиже, световая полоса, динамик с волнами + click, склейка на пике движения руки, таймлайн, БІР СТИЛЬ, плашка, поле комментария с набором «Claude».
  Найдено при своей проверке и исправлено до показа: белая заливка размытой руки в контуре (контур теперь строго снаружи силуэта), подписи с иконкой заходили под кнопки Reels.
- v3–v4 — пользователь прислал понравившийся ролик в **Premium Editorial** → тот же ролик в этом стиле: постеры (label + огромный sans + курсив/рукопись), графитовый фон снизу вверх с «до/после», контур, полноэкранная карточка МӘТІН, whip, разделённый экран со схемой, ч/б вспышка, панель АУЫСУЛАР, ч/б БІР СТИЛЬДЕ / кәсіби / МОНТАЖ, вспышка, финальный CTA, слышимые SFX.
  Исправлено при своей проверке: нижние крупные слова уходили под кнопки (центр смещается влево, ширина ≤ 0.7), голова закрывала вторую строку (anchorY 0.165), `keyT` кадров — на момент полной видимости.
- `npm run showcase -- breakdown` — разбор по дорожкам V1–V6, T, A1–A3 (секунда · шрифт · px · цвет · анимация · звук дБ).

## 7. Дальше
Ждём «Монтажды бастау» → `showcase -- approve` → `showcase -- render` → `cover` → `qc` → просмотр → отправка.

## Чему учит пример
- Время каждого приёма = время слова из транскрипта, склейка = пик движения из `study`.
- Сначала свой просмотр кадров (`showcase -- frames`), потом показ пользователю.
- Новый понравившийся стиль = новая версия той же раскадровки; одобрение — заново.
