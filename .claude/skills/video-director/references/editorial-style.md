# Premium Editorial стиль и showcase-монтаж

**Приоритет стиля не меняется:** прислал свой стиль (референс, скриншоты, слова) → делаем по нему (`reference.md`, разбор по дорожкам); этот стиль — только по умолчанию, когда своего нет.

Пользователю понравился этот стиль (ролик «Claude арқылы монтаж», ноябрь 2026). Используй его по умолчанию для экспертного видео с подробным брифом, когда просят «премиум», «как у дизайнеров», «моушн», «типографика», «как в прошлом ролике», и когда бриф требует эффектов, которых нет в стандартном `plan` (замена фона, контур, текст за человеком, переходы-панели). Слова пользователя важнее стиля.

Принцип: **слова управляют графикой.** Один смысловой блок = один главный приём, и он начинается на своём слове (время — из `work/transcript.json`, не на глаз).

## Путь (тот же порядок и та же защита одобрением)
1. `npm run new …` → `npm run transcribe` (сценарий → точный текст) → `npm run analyze` (лицо, склейки).
2. Силуэт на всё видео (для текста за человеком, замены фона, контура): `runAnalysis(["matte", <proxy>, work/matte/full, --start 0 --end <dur> --fps 30])` (~4 мин на 30 с). Посмотри один кадр на цветном фоне: волосы, пальцы.
3. Напиши `storyboard/showcase.json` (схема `src/showcase/spec.ts`, готовый образец — `references/example-showcase.json`): эффекты, камера, звуки, **`shots`** — строки раскадровки (№, время, экран, речь, текст, изменения, переход, `keyT` — момент, где всё видно).
4. `npm run showcase -- frames <id> t1,t2,… --scale 0.5` → **посмотри сам** каждую сцену: текст не на лице, в безопасной зоне, «за головой» читается (голова закрывает ≤ трети второй строки), низ кадра не под кнопками Reels.
5. `npm run showcase -- storyboard <id>` (contact-sheet + `shotlist.md`, версия растёт при любой правке, одобрение снимается) → `npm run showcase -- animatic <id>` → отправить три файла → «Монтажды бастау» / «Кадрды өзгерту».
5б. По просьбе «разложи по кадрам/дорожкам»: `npm run showcase -- breakdown <id>` → `breakdown.md` (каждый кадр: секунда · дорожка · что происходит, шрифт, размер, цвет, анимация, звук и его громкость) + `breakdown-tracks.png` (дорожки V1–V6, T, A3 как в монтажке).
6. Только после слов пользователя: `npm run showcase -- approve <id>` → `npm run showcase -- render <id>` → `npm run cover` → `npm run qc` (+ свой просмотр кадров) → SendUserFile.

## Дизайн-система (цвета/шрифты пользователя важнее)
| Роль | Шрифт (все с Ә Ғ Қ Ң Ө Ұ Ү Һ І) | Для чего |
|---|---|---|
| `sans` | Inter Tight 900, трекинг −0.045em | главное слово, огромно, розовым |
| `italic` | Cormorant Garamond 700 italic | элегантная вторая строка, слегка заходит на строку выше |
| `serif` | Cormorant Garamond 600 | спокойная строка |
| `script` | Bad Script | вопрос, пометка от руки, наклон −3…−5° |
| `label` | Inter Tight 700, КАПС, трекинг 0.18em | маленькая строка сверху/снизу |
Цвета: milk #F7F5F2, pink #F2D5E4 (главные слова), burgundy #8D263E (линии, подчёркивания), graphite #191919 (фактура). Без обводок, неона, случайных плашек.

## Приёмы (`effects` в showcase.json)
- **poster** — стек 2–4 строк: `label` → `sans` → `italic/script` → `label`. `anchorY` центр: над головой 0.165–0.185 с `behind: true` (человек перед текстом); ниже груди 0.6–0.7 с `bg: "shade-bottom"` (центр сам сдвигается влево от кнопок Reels). `bg`: `shade-top` · `shade-bottom` · `texture` (полноэкранная графитовая карточка, текст — главный) · `mono` (ч/б видео). Анимации: `word` (по словам в момент произнесения — `words` из транскрипта), `stagger`, `mask`, `script`, `scale`, `tracking`, `fade`. `front: true` + `y` — строка перед человеком; `underline: true` — бордовая линия. Выход `up` 0.22 с; следующая композиция — только после ухода предыдущей.
- **background** — замена фона: `texture: true` (графит) или цвет; `wipe: "up"|"right"`; `compare: [a, b]` — до/после с белым разделителем; `slideAt/slideX` — фон сдвигается и показывает исходный (два слоя).
- **contour** — белый контур строго снаружи силуэта (на лицо и руки не заходит), прорисовка от плеча.
- **behind** — одно огромное слово за человеком (`open`/`rise`).
- **label** — фраза-демо снизу (`icon`: layers · cc · speaker · cut; `underlineWord`; `wavesAt` для динамика).
- **schema** (Кадр → Мәтін → Нәтиже), **timeline**, **plate**, **comment** (поле комментария с набором текста).
- **split** — графитовая панель сверху, человек уезжает вниз. **mono** — ч/б вспышка. **sweep** — световая полоса за человеком.
- **transition**: `whip` (быстрая смазанная панорама), `type` (графитовая панель с огромным словом проходит справа налево — под ней меняется план), `flash`.
- **zoom**: `cut` — монтажный наезд (на пике движения руки: найди по разнице кадров), `ease` — плавный; не больше 1.4.
- Субтитры в этом стиле — только как демонстрация («Автоматты субтитр»); остальной текст — постеры (не дублировать).

## Звук (слышимый, но под голосом)
`reveal` (первая строка) · `whoosh` (крупный текст, панель) · `impact` (главное утверждение) · `tonal` (script, вопрос, финальное слово) · `swipe` (смена фона, переход) · `sweep` (вырезание) · `trace` (контур) · `click` (узлы, демо) · `pop` (последний узел, финал) · `riser` (перед главным) · `soft` (возврат из вспышки) · `type` (набор). Каждый — к конкретному движению, в момент его пика; паузы оставлять. `gain` 0.3–0.5 (библиотека уже ограничена по пику). Музыку не добавлять без файла пользователя.

## Проверка перед показом
Contact-sheet по `keyT` (момент полной видимости), отдельные кадры на стыках переходов, финальный кадр. Нельзя: текст на лице (кроме `behind`), текст в зоне кнопок справа снизу, обрезанные слова, два главных текста одновременно.
