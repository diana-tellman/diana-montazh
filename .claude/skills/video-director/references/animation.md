# Анимационный ролик (режим B)

Два пути. По умолчанию — **B1** (надёжный, проверенный кодом). **B2** — только когда нужен персонаж/своя графика, которых нет в B1.

## B1. Объясняющая анимация под голос пользователя (по умолчанию)
Материал: запись голоса пользователя (нет → `voice-captions.md`, «Текст для записи»). Без видео и фото проект сам переходит в режим «только аудио»:
- каждое предложение — своя анимированная карточка, без пустого фона: пример, сравнение А|Б, поток/шаги, орбита (перечисление), счётчик 0→N, заголовок «малая строка + БОЛЬШОЕ слово + рукописный хвост + иконка»;
- каждый элемент и звук появляется на своём слове; ≈ 1 звук в секунду;
- единый стиль во всех кадрах (одна палитра, одни шрифты, одни иконки) — это и есть «стиль сохраняется между кадрами».
Команды как обычно: `new` → `plan` → проверить `work/beats.json` → `directions.json` (тип карточки и 1–3 слова на ней для каждого предложения) → `storyboard` → `animatic` → одобрение → `render`. Обложка без лица: `npm run cover -- <id> --no-word --title "…"` (если скрипт не находит лицо — сообщи и предложи кадр `--t`).
Пиши сценарий маркерами смысла («мысалы», «… емес, …», «алдымен… содан кейін…», цифры) — тогда кадры строятся точнее.

## B2. Свой персонаж / свободная анимация
Когда просят персонажа, логотип, «мультик», промо без спикера.
- **Персонаж** — только из материала пользователя (его иллюстрация, PNG, фото) или нарисованный тобой в SVG/CSS. Генерация изображений нейросетью требует внешнего сервиса и ключа (см. `phone-cloud.md`) — предложи, но без согласия не используй. Лицо реального человека не генерируй.
- **Карточка персонажа** до раскадровки: силуэт, пропорции, 3 цвета (HEX), черты, одежда, что меняется и что никогда не меняется. Каждый кадр строится от неё (не от прошлого кадра) — так персонаж не «плывёт».
- Код: чистая графика без человека — **HyperFrames** (`npm run hf -- new projects/<id>/hf` → HTML + GSAP → `npm run hf -- render …`, правила в `tools.md`); с видео человека — Remotion (`showcase`). Затем проверки как в `render-delivery.md`. Одобрение раскадровки обязательно и здесь (код-гейта нет — соблюдай сам: не рендерить финал до «Монтажды бастау»).
- Раскадровка B2 — тот же формат, что `shotlist.md` (№, начало–конец, экран, речь, текст, изменения внутри кадра, переход) + 1 стоп-кадр на кадр (`npx remotion still`) в contact-sheet.

## Режиссура (из motion-studio, применимо к B1 и B2)
1. **Смысл раньше картинки**: одна фраза «что зритель поймёт/сделает»; каркас: крючок (0–3 с) → вопрос/проблема → механизм → доказательство/пример → вывод и читаемый финальный кадр (≥ 1.5 с). Каждый пункт каркаса — в конкретном кадре.
2. **Одна сквозная идея**: что действует, что меняется, что доказывает финал (трансформация героя, сквозной объект, match-cut). Для ключевых кадров перебери 2–3 варианта и выбери сильнейший — пользователю покажи только итог.
3. **Окно чтения**: ≈ 2.5–3 слова/с + 0.5 с на появление; одна главная мысль на кадр.
4. **Движение**: плавные разгоны/торможения, у объектов вес и инерция, текст участвует в действии; без хаотичного мельтешения. Тяжёлые пиксельные эффекты — заранее через ffmpeg, не CSS `blur()` на весь кадр.
5. **Проверка перед сдачей** (0–3 балла, порог): главная мысль понятна (3), композиция — ничего не обрезано (3), типографика и казахские глифы (3), стыки кадров без пустых кадров/скачков (3), синхронность с голосом ±2 кадра (2), технический экспорт (3). Непроверяемое (прослушивание) — так и назвать.

Музыка — только присланная пользователем (`--music`), всегда под голосом. Сами музыку не генерируем.
