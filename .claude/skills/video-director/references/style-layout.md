# Стиль, шрифты, композиция, камера, цвет

Цвета и слова пользователя всегда важнее палитры стиля.

## Типографика (kinetic-typography)

Код: `src/design/styles.ts`, `src/design/fonts.ts`, `src/compositions/Edit.tsx`.

| Стиль | Характер | Шрифт |
|---|---|---|
| `brand` (по умолчанию) | графит/бордо/белый, активное слово на бордовой плашке | Onest 800 |
| `minimal` | спокойный белый, золотой акцент | Inter 700 |
| `kinetic` | капс, слова выпрыгивают, красная плашка, без обводки | Montserrat 900 |
| `glass` | стеклянная плашка iOS, слова поднимаются | Onest 700 |
| `lime` | стикер: чёрный капс на лайме | Montserrat 900 |
| `bordeaux` | бордо/қызғылт/қара/ақ: бір сөз, жуан геометриялық, анимациясыз ауысу; постерлер Oswald + Bad Script; ақ фонда жылтыр бордо карточкалар | Montserrat Alternates 800 |
| `editorial` | премиум-постер: молочный/розовый, акцентные слова курсивом Cormorant | Inter Tight 800 |

Роли шрифтов в каждом стиле: субтитры (`font`), заголовки карточек/плашки/слово за головой (`titleFont`: Inter Tight, Montserrat, Geologica), акцентная строка (`accentFont`: курсив Cormorant, Bad Script).

- Шрифты встроены в репозиторий (npm @fontsource, OFL) и проверены по таблице символов на **Ә Ғ Қ Ң Ө Ұ Ү Һ І**: Onest, Inter, Inter Tight, Montserrat, Montserrat Alternates, Geologica, Rubik, Raleway, Nunito, Oswald, PT Serif, Cormorant Garamond, Bad Script. Нельзя (нет казахских букв): Manrope, Unbounded, Bebas Neue, Dela Gothic One, Great Vibes, Marck Script.
- Цвета пользователя всегда важнее палитры стиля. Тёмный акцент (бордо) показывается маркером под словом, а не цветом текста — иначе нечитаемо на видео.
- Акценты: `*слово*` в сценарии, числа — автоматически; иначе система сама выбирает одно длинное слово примерно в каждой третьей фразе.
- **Слово за головой** — крупное слово (≤12 букв) за силуэтом человека, ~1 раз на 15 с, только если над головой есть место. Силуэт вырезается MediaPipe по кадрам при рендере.
- Размер субтитров стандартный для Reels: ~48–56 px при ширине 1080. Обводку (stroke) не использовать — только мягкая тень.
- Позиция по умолчанию — внизу, сразу над «слепой» зоной интерфейса; выше — только если внизу мешает лицо.
- Межстрочный интервал 1.0–1.12, ≤2 строк, строки сбалансированы, без «висячих» слов. Строка, которая не помещается, автоматически ужимается в браузере.

### Стиль `bordeaux` (по умолчанию из `менің-талғамым.md`) — `--style bordeaux`
Взят из трёх референсов пользователя (тёмный explainer, эксперт со стеклянными виджетами, светлые схемы с красными узлами):
- **Субтитры** — как в референсе 3: **одно слово** за раз, жирный геометрический **Montserrat Alternates 800** (Λ-образные «л», «д»), строчные, плотный трекинг, **без анимации — жёсткая смена слова**. На видео белые с мягкой тенью, на светлой панели — чёрные. `*Акценты*` розовые (#F4A6C0) на видео, бордо (#9B1C40) на светлом. Высота ≈ 66 % (на уровне груди).
- **Постеры** — тонкая строка над БОЛЬШИМ узким словом **Oswald** бордо, рукописная строка **Bad Script**, наклон −3°; числа считают.
- **Схемы** — светлая панель (#F4F1EE) с точечной сеткой, **глянцевые бордовые карточки** (градиент + блик сверху + мягкая цветная тень), белые значки, чёрные подписи. Это не «стекло» — стекло только у виджетов поверх видео.
- **Виджеты на видео** — тёмное стекло, бордовые значки, розовые детали.

Другие стили: `brand`, `minimal`, `kinetic`, `glass`, `lime`, `editorial` (Inter Tight + курсив Cormorant). Слова пользователя важнее стиля.


## Композиция и безопасные зоны (smart-layout)

Код: `src/layout/frame.ts` (одна функция кадрирования для планировщика и рендера), `src/layout/safeZones.ts`, `config/safe-zones.json`, `src/plan/validate.ts`.

- **Кадрирование**: если пропорции исходника близки к формату — `cover` (лицо в верхней трети, края кадра никогда не видны); если сильно отличаются (горизонтальное видео в 9:16) — `contain` + размытый фон, готовый заранее через ffmpeg. Растягивания нет никогда.
- **Зум** ограничен так, что голова (от макушки по сегментации волос до подбородка) целиком в кадре.
- **Безопасные зоны** — `config/safe-zones.json` (нормированные, редактируемые). Значения консервативные: интерфейс отличается по устройствам.
- **Защита лица**: зона = овал лица + 18% по ширине (волосы/уши), от макушки до подбородка, объединённая по всему времени субтитра с учётом движения камеры. Порядок: та же позиция что у прошлого субтитра → под подбородком → нижняя треть → над головой → верх; затем уменьшение до 0.72. Если не помещается — ошибка в сториборде и предложение другого layout.
- **Кнопки Instagram/Shorts/TikTok** (колонка справа внизу): `lowRight` в `safe-zones.json` — ниже 62 % высоты правый край текста ≤ 82 % ширины (Reels), полоса субтитров там уже.
- **Карточки макетов** (`cardRect` в `src/layout/person.ts`) — запретная зона для субтитров, иконок и плашек; лицо в окне/половине экрана защищено так же, как на весь кадр (по конечному положению после анимации переезда).
- На кадрах сториборда: жёлтый пунктир — безопасная зона, красное — интерфейс, зелёная рамка — защищённая зона лица.

## Камера, макеты, иконки, плашки (motion-graphics)

Код: `src/plan/planner.ts` (камера, сцены), `src/compositions/Edit.tsx`.

- **Камера (expert-video)**: планы делятся по склейкам исходника и паузам каждые ~3.5 с; зум чередуется 1.0 / 1.12 / 1.04 / 1.16 (jump-cut зум), на акцентной фразе длинного плана — плавный наезд 0.9 с. `--energy 0` — статично, `2` — энергичнее.
- **Фото (voice-over-visuals)**: равные отрезки по границам фраз, медленный наезд Ken Burns.
- **Только голос**: анимированный градиентный фон в цветах бренда + крупные субтитры.
- **Макеты** (`layouts` в storyboard.json, опция `--layout`):
  - `full` — человек на весь кадр (по умолчанию);
  - `circle` — человек в круге с белой рамкой поверх фото/клипа/фона бренда («адамды шеңберге салу»);
  - `split` — экран делится: сверху фото/видео, снизу человек, между ними акцентная линия;
  - `pip` — спикер переезжает (анимация 0.35 с) в скруглённое/круглое окно сверху, ниже — карточка примера (по слову «мысалы/например»); присланное фото/клип идёт фоном;
  - `compare` — сверху карточки А | VS | Б, снизу спикер (сравнение);
  - `explainer` — спикер уходит из кадра (круговое раскрытие), полноэкранная схема шагов под голос (процесс);
  - `auto` (по умолчанию) — макеты выбираются по смыслу речи (`meaning-to-frame.md`, `src/plan/director.ts`); оставшиеся присланные фото/клипы — моменты split-screen (≈1 на фото, 2.5–4.5 с, границы совпадают с субтитрами).
  - Отрезок вручную: добавить в `layouts[]` `{id, start, end, kind, secondary, secondaryKind, secondaryW, secondaryH}` и `npm run storyboard`.
- **Иконки по смыслу** (`icons[]`, `src/design/icons.ts`): своя библиотека линейных иконок (телефон, деньги, время, идея, галочка, сердце, звезда, рост, видео, чат, колокольчик-подписка, внимание, огонь, цель, книга, подарок, ссылка, глаз). Появляются, когда звучит слово-ключ (kk/ru/en), рисуются линией, «выпрыгивают» со звуком pop, не чаще 1 раза в 3.5 с, никогда не на лице и не на субтитре. Нет места — иконка не ставится. Выключить — `--no-icons`; убрать одну — удалить из `icons[]`; добавить — вписать `{id, start, end, name, x, y, size: 0.17, word}`.
- **Плашки** (`callouts`): `glass` — стекло, `tag` — белый ярлык, `cta` — кнопка с мягким свечением. Добавлять по просьбе или в финальной фразе с призывом.
- **Производительность**: размытие/цветокоррекцию делает ffmpeg заранее. Не добавлять CSS `filter: blur()` на полноэкранное видео (в облаке без GPU — в 3 раза медленнее).

## Цвет и звук (color-sound)

- **Цвет**: при подготовке ffmpeg переводит HDR (HLG/PQ, Dolby Vision iPhone) в SDR BT.709 мягким tone mapping (`mobius`), без пересыщения и резкости (`src/core/transcode.ts`). Цвет кожи не стилизуется.
- **Голос** (`src/audio/enhance.ts`): только коррекция — срез гула 70 Гц, лёгкое шумоподавление, де-эссер, мягкая компрессия, −16 LUFS. Тембр и высота не меняются. Голос никогда не заменяется.
- **Финал**: двухпроходная нормализация −14 LUFS, true peak ≤ −1 dBTP, проверка клиппинга в `npm run qc`.
- **Звуки** (`src/audio/sfx.ts`) — свои, синтезированные: `pop` (акцент, карточка, кнопка), `whoosh` (слово за головой, переезд в окно), `swipe` (схема), `click` (шаг схемы), `impact` (второй пункт сравнения), `soft` (смена плана, плашка), `tick`, `riser`. Каждый — в момент появления своего элемента, не чаще 1 раза в секунду, gain 0.14–0.2. «Без звуков» → `--no-sfx`; убрать один — удалить из `sfx[]`.
- **Музыка** — только файл пользователя (или с понятной лицензией): `--music <файл>`. −18 LUFS, под речью ×0.07 (≈ −19 дБ к голосу), в паузах ×0.2, плавные переходы 0.25 с, fade-in/out. Если в видео уже есть музыка — не добавлять.
