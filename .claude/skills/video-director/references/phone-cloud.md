# Телефон, облако, GitHub, ключи

## Как всё работает
Claude Code в приложении Claude (iPhone) → облачная сессия с репозиторием `diana-montazh` (копия ученика). Рендер, распознавание речи и проверки идут **в облачном контейнере сессии**, не на телефоне и не в GitHub Actions. Телефон нужен только для чата: отправить файл, ответить, получить MP4/PNG/PPTX. Отдельный сервер, GitHub Actions или внешние API **не нужны**.

## Файлы с телефона
- До ~25–30 МБ — прикрепить в чат (скрепка → Фото / Файлы). Вложения сохраняются в сессии.
- Больше — Google Drive / iCloud ссылка с доступом «всем, у кого есть ссылка» → `npm run fetch -- <url>` (нужен хост в сети среды: `drive.google.com`, `drive.usercontent.google.com`).
- Instagram/TikTok/YouTube-ссылки обычно не скачиваются → попроси сохранить видео в «Фото» или записать экран (Пункт управления → Запись экрана) и прислать файл.
- Голос: «Диктофон» → запись → Поделиться → Claude (M4A).

## Получение результата
SendUserFile → в чате карточка файла → открыть → «Бөлісу → Видеоны сақтау» (MP4) / «Файлдарға сақтау» (PPTX). Файл не открылся/не дошёл → перерендер с `--max-mb 90`.

## Среда (один раз, ученик делает с телефона — `STUDENT-GUIDE.md`)
- Сеть: «Ограниченный» + «Разрешить менеджеры пакетов» (+ Google Drive при ссылках).
- Скрипт настройки: `setup/cloud-environment.sh` (ставит зависимости и модели заранее ~2 мин).
- SessionStart-хук `.claude/hooks/session-start.sh` сам делает `npm ci`.
- Коммитить можно только код и `менің-талғамым.md`; медиа — никогда.

## Внешние сервисы и ключи
| Функция | Нужен ли ключ | Чем закрыто без ключа |
|---|---|---|
| распознавание речи, лицо/силуэт, рендер, звук, обложка, PPTX | **нет** (локальные модели, скачиваются с GitHub Releases и Google Storage, проверка SHA-256) | — |
| скачивание по ссылке | нет (нужен доступ к хосту в сети среды) | файл в чат |
| генерация картинок/персонажа нейросетью (B2) | **да** — внешний сервис (Krea, OpenAI Images и т. п.), платно/лимиты; только с согласия пользователя | иллюстрации пользователя или SVG-графика |
| синтез голоса | **запрещено** правилами студии | только голос пользователя |
