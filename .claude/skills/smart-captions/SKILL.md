# Smart Captions

Код: `src/speech/*`, `scripts/transcribe.ts`, `src/plan/phrases.ts`.

- `npm run transcribe -- <id>` — локально: Whisper large-v3-turbo + Silero VAD (sherpa-onnx). Модели качаются сами (~564 МБ, один раз за сессию) и проверяются по SHA-256. `plan` вызывает это автоматически.
- **Казахский распознаётся хуже русского.** Если есть текст сценария — всегда используй его (`--script` при `new`): слова берутся из сценария, время — из записи. Без сценария — обязательно попроси проверить текст на сториборде.
- Готовые субтитры: `npm run transcribe -- <id> --import file.srt|.vtt|.txt` (txt: строки «0:03.5 текст»).
- Исправление слова — правка `storyboard.json` (skill `storyboard-builder`), не перераспознавание.
- Время фраз измерено по аудио; время отдельных слов — оценка внутри фразы. Сообщай об этом честно.
- Фразы: ≤3–5 слов (по стилю), разрыв на паузе ≥0.45 с и знаках препинания, ≤2 строки, активное слово подсвечено.
